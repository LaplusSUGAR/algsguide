# DROPZONE v3 — 서버 연동 버전
2026-10-28. 기존 HTML 디자인을 유지하고 실제 서버 저장과 외부 수집을 추가했습니다.

## 빠른 시작 (PC, Node.js 24 이상)
1. ZIP을 완전히 압축 해제합니다.
2. 이 README와 package.json이 있는 폴더에서 터미널을 엽니다.
3. `npm install` — 푸시 발송 라이브러리를 설치합니다.
4. `node setup.mjs` — .env와 관리자 비밀번호를 생성합니다. 화면에 한 번 표시되는 비밀번호를 안전하게 보관하세요.
5. `npm start`
6. 브라우저에서 http://localhost:3000 을 엽니다. `website/index.html`을 더블 클릭하면 서버 없는 체험 모드입니다.
7. 우측 '관리'에서 발급된 관리자 비밀번호로 로그인합니다. 방문자는 로그인할 필요가 없습니다.

푸시 패키지 설치가 실패해도 핵심 서버는 Node 내장 기능만으로 실행 가능합니다. 이 경우 VAPID_SUBJECT를 비워 두고 `npm start`로 시작하세요. 푸시를 활성화하기 전에 npm install을 완료해야 합니다.
종료는 Ctrl+C. 서버가 꺼져 있으면 데이터 수집과 푸시 발송도 중단됩니다. 나중에 24시간 운영 서버에서 실행해야 상시 동작합니다.

## 추가된 기능
- SQLite 공용 저장: 공지, 질문, 답변, 일정, 채널
- 관리자 로그인: scrypt 비밀번호 해시, HttpOnly 세션 쿠키, 8시간 만료
- 익명 Q&A: 비밀번호 수정·삭제, 관리자 답변, 도배 및 비밀번호 시도 제한
- EA 공식 사이트 순위: 지역별 1분 주기 수집, 마지막 정상 결과 유지, 갱신 지연·오류 표시
- YouTube: 등록 채널의 현재 공개 생방송 확인
- 치지직: 공식 라이브 목록 조회, 불완전 조회 시 '미확인' 표시
- X: 최신 게시물 확인 (X 생방송 감지는 아님)
- 활동 알림 목록: 새 방송/게시물 감지, 중복 방지, 첫 조회 알림 억제
- 웹 푸시: 관심 채널 선택, 브라우저 동의, 구독/해제, 스포일러 없는 알림
- 챔피언십: 공식 사이트 포인트 5분 주기 자동 수집. 지역 순위와 가상 추가 점수 계산

## 실제 연결에 필요한 설정
setup 후 .env를 텍스트 편집기로 수정하고 서버를 재시작합니다. API 키를 코드·게시글·채팅·Git에 넣지 마세요.

### YouTube
Google Cloud 프로젝트에서 YouTube Data API v3를 활성화하고 서버용 API 키를 발급받아 YOUTUBE_API_KEY에 넣습니다. 브라우저 리퍼러 제한 키는 서버 호출에 맞지 않습니다. API 제한과 사용량을 콘솔에서 확인하세요.
채널 등록 URL은 `https://www.youtube.com/channel/UC…` 또는 `https://www.youtube.com/@handle` 형식입니다.
기본은 채널별 30분 이상 간격, 하루 총 검색 90회 제한입니다. 순번대로 조회하므로 채널이 많으면 갱신이 더 늦어집니다. 검색 할당량을 소모하는 작업이라 초 단위 실시간은 아닙니다. 새 업로드 영상 수집은 이번 버전에 포함되지 않았습니다.
https://developers.google.com/youtube/data/getting-started
https://developers.google.com/youtube/data/reference/rest/v3/search/list

### 치지직
치지직 개발자 센터에서 앱을 등록하고 Client ID / Client Secret을 CHZZK_CLIENT_ID, CHZZK_CLIENT_SECRET에 입력합니다.
채널 주소는 `https://chzzk.naver.com/32자리채널ID` 또는 `/live/32자리채널ID`입니다.
5분 주기로 공식 목록을 20개씩, 기본 최대 20페이지까지 조회합니다. 전체 목록을 다 보지 못했으면 목록에 없는 채널을 OFFLINE으로 단정하지 않습니다. 호출량을 검토하며 CHZZK_MAX_PAGES를 조정하세요.
https://chzzk.gitbook.io/chzzk/chzzk-api/live
https://chzzk.gitbook.io/chzzk/chzzk-api/tips

### X
X 개발자 계정의 읽기 권한이 있는 Bearer token을 X_BEARER_TOKEN에 입력합니다. 계정의 요금·크레딧·호출 권한에 따라 비용 또는 접근 제한이 있을 수 있습니다. 코드가 요금제 가입이나 결제를 수행하지는 않습니다.
채널 주소는 `https://x.com/사용자이름`입니다. 채널별 15분 이상 간격으로 조회하며 현재는 회당 최근 5개 중 최신 게시물만 표시합니다. 조회 사이에 여러 게시물이 올라오면 모두 보존하지 않습니다. 생방송/스페이스 감지는 포함되지 않았습니다.
https://docs.x.com/x-api/users/get-posts
https://docs.x.com/x-api/users/get-user-by-username

### EA 공식 대회 결과 (API 키 불필요)
수집원은 algs.ea.com 공식 웹사이트가 사용하는 `https://prod-api.algstools.com/v1`입니다. 공식 페이지의 공개 JavaScript에서 주소와 호출 형식을 확인했고 실제 JSON 응답을 받았습니다. 이전 점수 공급자로의 호출이나 장애 시 대체 수집은 없습니다.

- 시즌 구조: `/seasons/structure` (10분 간격)
- 지역/대회 단계 순위: `/stats/phases/{phaseId}/standings` (지역별 1분 간격)
- 챔피언십 팀 포인트: `/seasons/{seasonId}/standings/teams` (5분 간격)

기본은 `isMainSeason`인 시즌과 각 지역에서 시작 시각이 지난 가장 최근의 공개 대회를 선택합니다. 순위를 제공하는 단계만 대상이며, 최신 단계의 결과가 비어 있으면 앞 단계 중 결과가 있는 단계를 선택합니다. 아직 시작하지 않은 대회를 진행 중으로 표시하지 않습니다. 데이터 수집 시각과 대회 진행 시각은 다릅니다.
지역 탭은 실제 지역별 캐시를 조회합니다. APAC North, 세계대회, Americas, EMEA, APAC South를 지원합니다. 화면에 대회명·단계명·공식 원문 링크가 표시됩니다.

대회를 고정하려면 .env의 EA_EVENT_APAC_NORTH / EA_EVENT_GLOBAL / EA_EVENT_AMERICAS / EA_EVENT_EMEA / EA_EVENT_APAC_SOUTH에 위 공식 시즌 구조에서 반환된 대회 ID를 입력하세요. EA_SEASON_ID는 선택 사항입니다. 키가 아니라 공개 데이터의 식별자입니다. 임의로 추측한 ID를 사용하지 마세요.

챔피언십은 2026-10-28에 확인한 공식 페이지와 동일하게 Year 6 최소 12경기 필터 및 지정된 이벤트 ID 4개를 사용하며, 팀 totalPoints를 재합산하지 않고 원본 그대로 표시합니다. 해당 설정은 `server/ea.mjs`에 근거와 함께 있습니다. 공식 페이지의 규칙/필터가 바뀌면 업데이트가 필요합니다. 새 시즌의 슬롯은 자동 추정하지 않고 미확인으로 표시합니다.

한국 선수 소속 여부는 공식 선수 country=KR 정보로 표시하고, 챔피언십 응답에 국적이 없으면 동일한 player ID의 공식 지역 순위 국적 정보를 연결합니다. 국적 정보가 없는 경우 한국 팀으로 추정하지 않습니다.

순위의 qualificationThreshold는 해당 단계의 통과 기준입니다. 세계대회 최종 출전권의 모든 조건을 의미하지 않습니다. 가상 점수 계산은 전체 동점 규칙·로스터 이동·별도 예선 경로를 평가하지 않으므로 진출 확정/확률을 판정하지 않습니다. 가상 값을 넣기 전 순위는 원본 공식 rank/position을 표시합니다.

예전 .env의 ALS_SCORE_URL, CHAMPIONSHIP_FEED_URL, PLAYOFFS_FEED_URL은 더 이상 읽지 않습니다. 기존 DB의 과거 공급자 캐시는 화면에 사용하지 않습니다. 수동 순위 업로드 API도 비활성화했습니다.

이 경로는 공식 사이트가 사용하는 공개 응답이지만 별도의 장기 제공 계약이나 개발자 API 안정성을 보장하는 것은 아닙니다. 구조 변경·접근 제한 시 마지막 정상 결과와 오류를 표시하고 다른 데이터 공급자로 전환하지 않습니다.
원본: https://algs.ea.com/en/championship-points

### 웹 푸시
setup.mjs가 VAPID 공개키·비밀키를 생성합니다. VAPID_SUBJECT에 실제 운영 연락처를 `mailto:주소` 형식으로 넣고 서버를 재시작합니다. 이메일 주소는 방문자로부터 받는 것이 아니라 푸시 서비스에 제출하는 운영자 연락처입니다.
HTTPS 또는 localhost의 지원 브라우저에서 선수·방송 채널을 즐겨찾기한 뒤 알림 페이지의 '푸시 허용 / 즐겨찾기 적용'을 누릅니다. 즐겨찾기를 바꾼 후 다시 눌러 구독 대상을 갱신해야 합니다.
푸시 구독 주소·브라우저 암호키·선택한 채널 ID가 서버 DB에 저장됩니다. 해제 버튼으로 삭제할 수 있습니다. 90일 이상 갱신되지 않은 구독은 다음 푸시 처리 때 제거합니다. 404/410 종료 구독도 삭제합니다.
처음 확인한 기존 방송·게시물은 알리지 않고 이후 새 이벤트만 알립니다. 중복은 제거합니다. 실패한 푸시의 재전송 큐는 없으므로 모든 알림 전달을 보장하지 않습니다. 모바일 OS/브라우저 정책에 따라 설치 및 알림 허용 조건이 달라집니다.
https://github.com/web-push-libs/web-push

## 운영 주소와 도메인 연결
이번 버전은 Node 서버가 필요합니다. Cloudflare Pages에 HTML만 드래그하면 서버 기능은 작동하지 않습니다.

1. Node.js 24 이상을 지원하는 VPS 또는 지속 실행 호스팅을 준비합니다. 서버 구매/결제는 수행하지 않았습니다.
2. 파일을 배치하고 `npm install`, `node setup.mjs`를 실행합니다. .env와 data 폴더는 공개 경로에 올리지 않습니다.
3. data/에 쓰기 권한과 영속 디스크를 제공합니다. SQLite 한 개를 사용하는 단일 프로세스 배포를 전제로 합니다. 여러 서버의 파일시스템을 공유하는 구성은 지원하지 않습니다.
4. .env의 PUBLIC_ORIGIN을 실제 `https://내도메인`으로 변경합니다. 마지막 슬래시는 넣지 않습니다. 기본 localhost 주소를 바꾸지 않으면 POST 요청이 거절됩니다.
5. VPS 예시: Node는 127.0.0.1:3000에 두고 Caddy가 80/443에서 HTTPS를 처리합니다. 도메인 DNS A/AAAA를 서버로 연결하고 Caddyfile.example의 도메인을 실제 값으로 교체합니다.
6. systemd 예시를 환경에 맞게 수정하면 서버 재부팅 후 자동 시작할 수 있습니다. User, Node 경로, 작업 경로는 실제 설치와 일치해야 합니다.
7. 로컬 Caddy만 앞에 있는 경우 TRUSTED_PROXY_IP를 실제 소켓 주소(예: 127.0.0.1)로 지정할 수 있습니다. 알려진 프록시 외의 주소를 신뢰하도록 설정하지 마세요. 비워두면 접속 제한은 서버가 직접 보는 IP 기준입니다.
8. Dockerfile도 포함했습니다. .env는 실행 시 환경변수로 전달하고 /app/data를 영속 볼륨에 연결해야 합니다. 컨테이너 포트를 외부에 직접 열지 않고 HTTPS 역방향 프록시 뒤에 두세요.

https://caddyserver.com/docs/quick-starts/reverse-proxy

## 저장, 백업, 이전
기존 로컬 HTML의 브라우저 데이터는 새 서버로 자동 이전하지 않습니다. 실제 공유할 공지·일정·채널은 서버 관리자 화면에서 다시 등록하세요.
서버를 정상 종료한 뒤 data 폴더 전체를 백업하면 SQLite와 관련 파일을 함께 보관할 수 있습니다. 운영 중에는 SQLite 백업 기능을 사용하세요. .env도 별도의 비공개 안전한 위치에 보관하세요.
관리자 비밀번호를 잃었다고 data를 삭제하지 마세요. .env의 ADMIN_PASSWORD_HASH를 새로운 해시로 교체하면 되며 기존 게시글은 유지할 수 있습니다.
서버 재시작 시 관리자 세션은 만료되어 다시 로그인해야 합니다.

## 검증 범위
`npm test`로 권한·CSRF·질문 비밀번호·저장/재시작·순위 동점·API 응답 변환·부분 조회·중복 알림·오류 시 캐시 유지 테스트를 실행할 수 있습니다. 이 테스트들은 통제된 API 응답을 사용합니다.
공식 시즌 구조, APAC North 단계 순위(30팀), 챔피언십 포인트(120팀)의 실제 JSON 응답을 확인하고 변환기를 검증했습니다. 진행 중인 경기의 매 초 갱신 또는 모든 지역의 실경기 검증은 아닙니다. 공식 사이트 자체 갱신 주기와 지연이 적용됩니다.
YouTube/치지직/X의 실제 계정 인증은 키가 없어 검증하지 못했습니다. 푸시 실제 발송은 실제 구독과 VAPID 설정이 없어 미검증입니다. 작성 환경에서 web-push 의존성 설치도 네트워크 제한으로 끝내지 못했으므로 사용자 환경에서 npm install을 완료해야 합니다.

## 편집용 소스
source/에 React/TypeScript/CSS가 있습니다. 기본 실행에는 프런트엔드 빌드가 필요하지 않습니다.
화면을 바꾼 뒤 루트에서 `npm run build`를 실행하면 website/index.html이 갱신됩니다. 서버 코드 수정 후에는 서버를 재시작합니다.
API 키·실제 관리자 비밀번호·게시글 DB·node_modules는 배포 ZIP에 포함하지 않았습니다.
